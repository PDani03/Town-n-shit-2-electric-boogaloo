2026.10.02, Patch 1.3:

    big changes:
        uploaded to github
        added settings menu to town
            added combat QoL setting (off by default): skips the "press enter" pauses after enemy attacks, after defeating an enemy and after weapons drop
        bows now raise your max focus (max focus = base accuracy * bow value * 2, never lower than the normal 2 * base accuracy)

    small changes:
        reworded last floor message
        changed cave color to a more readable gray

    fixes:
        fixed bug where you could only pick attack or defend when picking "drink potion" while you are out of potions
	    the last floor is now floor 50 (there used to be an extra floor 51)
        fixed colors not showing in some Windows consoles
        fixed the game crashing when choosing an enemy number that doesn't exist
        added club weapon to the reward chest loot

2026.02.25, Patch 1.2:

    big changes:
        added new weapon type - club
            provides value*0.7 damage, negates enemy defense

    small changes:
	    added auto focus option to combat: picks defend every turn until max focus is reached

2026.02.22, Patch 1.1:

    big changes:
        added color
        added new weapon type - dagger:
            provides value*1.2 damage, but also *0.8 defense (so if you have it equipped you do more damage but have less defense)
            you lose more focus with it equipped (0.02 -> 0.03)

    small changes:
        changed enemy floor scaling (less scaling on hp, more on dmg and df)
        listWeapons() now orders weapons according to type, then value
        selling a weapon now puts you back at sell weapons area instead of shop
        focus is now kept between 0 and 2 * base accuracy
        you now gain less focus when guarding (0.045 -> 0.03)
        you now lose less focus if a bow is equipped (0.02 -> 0.01)
        added extra usefulness to the place you go into
        increased money gained from selling weapons

    fixes:
        fixed lower difficulties making prices scale down
        fixed potions not running out
